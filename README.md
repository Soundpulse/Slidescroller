# Slidescroller

### Endless runner with procedural map generation

A Unity side-scrolling runner prototype with procedurally generated maps.

## Repository structure

| Path | What it is |
| --- | --- |
| `Assets/RunnerMapGeneration` | Procedural map/level generation for the runner. |
| `Assets/Scenes` | Game scenes. |

## Getting started

Open the project folder in the Unity Editor (see `ProjectSettings/` for the target version) and load a scene from `Assets/Scenes`.
